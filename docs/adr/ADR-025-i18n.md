# ADR-025 — Bağımlılıksız TR/EN arayüz

**Durum:** Kabul edildi (28 Ekim 2026). **Kart:** WB-022A. Kaynak: PRD FR-11, API Contract §7.

## Karar

- `t(source, params)`: anahtar Türkçe kaynak metnin kendisidir, `{ad}` yer tutucuları doldurulur; İngilizce
  `apps/web/src/i18n/en.ts` kataloğundan gelir, eksikse kaynak metin gösterilir. Yeni bağımlılık yok.
- Dil modül düzeyinde tutulur; saf modüller (validator mesajları, simülasyon adımları, hata eşlemeleri) mesajı
  üretildiği anda çevirir. React tarafı `useSyncExternalStore` ile yeniden çizer; editör durumu ve geri alma geçmişi
  korunur. React Flow kartları ve önbelleğe alınmış mesajlar dili memo anahtarına ekler.
- Sabit etiket/hata haritaları Türkçe kalır, kullanıldıkları yerde `t()` ile çevrilir. Sunucunun `messageKey`'leri
  ve API hata kodları dil bağımsızdır; istemci kendi metnini gösterir.
- İlk dil: kayıtlı seçim, yoksa tarayıcı dili (`tr*` → TR, aksi EN). Seçim `localStorage`'da; `<html lang>`
  güncellenir. AI istekleri ve yeni/örnek akışlar seçili dili kullanır; kullanıcı içeriği (adım adları) çevrilmez.
- Kalite kapısı: AST tabanlı test her `t()` kaynağının ve çevrilen harita değerinin katalogda olduğunu, yer tutucuların
  aynı olduğunu, katalogda fazlalık olmadığını ve `t()` dışında Türkçe metin kalmadığını doğrular.

## Sonuçlar

Katalog 390 giriş. Türkçe kaynak metin değişirse anahtar değişir; test eksik çeviriyi hemen yakalar.
