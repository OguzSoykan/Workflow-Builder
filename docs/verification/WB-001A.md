## Probe'ların tekrar üretimi

İlgili paketin `src/` altında geçici `.ts` dosyası oluşturup `npm run typecheck --workspace=<paket-adı>` çalıştırın; sonra yalnızca bu geçici dosyayı kaldırın. Negatif örneklerin başarısız olması beklenir. Geçici örnekler teslimde kalmaz.

- Strict: `export function probe(value) { return value; } export const required: string = null; export const count: number = "invalid";`
- Public import: `import * as contract from "@workflow-builder/workflow-contract"; export { contract };` (web/worker için core da aynı biçimde).
- Internal import: `import * as probe from "@workflow-builder/workflow-contract/src/index.ts"; export { probe };`
- Ortam sızıntısı: `export const probe = [document, fetch, process];`
- App import: `import * as web from "@workflow-builder/web"; export { web };`

Export map göreli filesystem import'larını veya npm hoisting'i tam engellemez; bu sınır ADR-012'de ve sonraki lint görevinde izlenir. Şu an package import davranışı ve ambient type sınırı doğrulandı; bir runtime sandbox iddiası yok.
