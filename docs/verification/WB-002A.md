# WB-002A — Şema v1

Strict Zod şeması dört node/beş input türünü, finite sayıları, gerçek takvim tarihini, kimlik benzersizliğini, bilinmeyen alan reddini ve sınırlı JSON parsing'i uygular. Public giriş `parseWorkflow(unknown)`; `WorkflowSchema` güvenilir araçlar/JSON Schema üretimi içindir. Güvenilmeyen girdilerde ön korumayı atlayıp doğrudan Zod kullanmayın.

`npm run typecheck`, `npm run lint` ve `npm test` geçti (24 şema/tarih testi + 6 mevcut Worker testi). Başarı örneği bütün node/input varyantlarını kapsar. Duplicate node/edge/key, unsupported version/type/handle, malformed edge, yanlış default/options/config reddedilir. Derinlik/byte ve diğer hostile-input matrisleri WB-002C/003C'de genişletilecek.

[ADR-013](../adr/ADR-013-contract-and-validation.md) D-01/02/04/15'in Faz 1 ayrıntılarını tanımlar. Topolojik tamamlanmışlık ayrı core görevidir; schema eksik graph'ı temsil edebilir. Taslak saklama kararı verilmedi.

Öz inceleme: uygulama/secret/deploy yok; `@noble/hashes` taşınabilir UTF-8 yardımcıları ve takip eden hash kartı için, Zod tek şema kaynağı olarak kullanılır. Kaynaklar strict, ortak paketlerde Node/DOM globals yok. Hosted CI/merge kanıtı PR üzerinden izlenir.
